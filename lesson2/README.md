# Урок 2: Линейная и логистическая регрессия на PyTorch

В этом уроке:
- Реализуем линейную и логистическую регрессию на PyTorch-тензорах с ручным вычислением градиентов (без autograd)
- Реализуем то же самое с помощью встроенных слоев и оптимизаторов PyTorch
- Познакомимся с концепцией цикла обучения (training loop)
- Научимся логировать метрики обучения
- Научимся сохранять веса и использовать state_dict
- Научимся работать с реальными датасетами из sklearn (diabetes, breast_cancer)
- Познакомимся с концепцией Dataset-классов для обёртки данных
- Научимся использовать DataLoader для обучения по батчам

## Структура
- `linreg_manual.py` — линейная регрессия "руками"
- `logreg_manual.py` — логистическая регрессия "руками"
- `linreg_torch.py` — линейная регрессия на nn.Linear, MSELoss, torch.optim
- `logreg_torch.py` — логистическая регрессия на nn.Linear, BCEWithLogitsLoss, torch.optim
- `utils.py` — вспомогательные функции (логирование, генерация данных, метрики, загрузка датасетов, классы Dataset)

## Использование реальных датасетов
В функциях `make_regression_data` и `make_classification_data` можно указать параметр `source`:
- Для регрессии: `'random'`, `'diabetes'`
- Для классификации: `'random'`, `'breast_cancer'`

**Задание**: попробуйте датасеты не random в случае линейной и логистической регрессии

## Dataset-классы и DataLoader
В `utils.py` реализованы классы `RegressionDataset` и `ClassificationDataset`, которые наследуются от `torch.utils.data.Dataset`:
- `__len__()` — возвращает размер датасета
- `__getitem__(idx)` — возвращает пару (X[idx], y[idx])

`DataLoader` используется для:
- Разбиения данных на батчи (batch_size=32)
- Перемешивания данных (shuffle=True)
- Итерации по батчам в цикле обучения

## Решение домашнего задания

Команды ниже запускаются из корня репозитория. Все три скрипта работают на CPU.

```powershell
python -B -X utf8 -m lesson2.homework_model_modification
python -B -X utf8 -m lesson2.homework_datasets
python -B -X utf8 -m lesson2.homework_experiments
python -B -X utf8 -m unittest lesson2.test_homework -v
```

| Скрипт | Что делает |
| --- | --- |
| `homework_model_modification.py` | Сравнивает линейную регрессию с L1 и L2, применяет раннюю остановку, обучает многоклассовую модель и сохраняет матрицу ошибок. |
| `homework_datasets.py` | Загружает CSV через `CSVDataset`, обучает линейную и бинарную логистическую регрессию, выводит тестовые метрики. |
| `homework_experiments.py` | Сравнивает пять запусков. В каждом опыте меняется один параметр относительно базового запуска. Отдельно проверяет влияние новых признаков. |

`homework_training.py` содержит модели, общий цикл обучения и расчёт метрик для трёх скриптов.

### Данные и результаты

- Все скрипты читают `models/winequality-red.csv`. В исходнике 1599 строк, 11 физико-химических признаков и целевая оценка `quality` по шкале от 0 до 10. После исключения точных дублей в памяти остаются 1359 строк. Разбиение на train, validation и test одинаково для всех задач и сохраняет доли исходных оценок.
- Регрессия предсказывает числовой балл. Для бинарной классификации оценки 6–10 считаются положительным классом, оценки 0–5 — отрицательным. Многоклассовая модель различает шесть оценок, которые встречаются в файле, от 3 до 8.
- `plots/` содержит кривые валидации L1 и L2, матрицы ошибок, графики экспериментов и CSV-таблицы сравнения. `models/` содержит веса и настройки предобработки. Файл весов читается через `torch.load(path, map_location="cpu", weights_only=True)`. Чтобы восстановить линейный слой, создай `nn.Linear` с размерами `in_features` и `out_features` из файла и передай `state_dict` в `load_state_dict()`.
- В `test.md` собрана теория для защиты и разобраны результаты проверочного запуска.
